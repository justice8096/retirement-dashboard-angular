## Proportional — math reference

```
draw[account] = residual × balance[account] / Σ balances
```
Preserves current account-mix ratio. Fallback when every balance is 0: full residual from Traditional.

## Tax-efficient — math reference

```
Draw order: Taxable → Traditional → Roth (cap each at its balance).
Any residual still uncovered overflows to Traditional.
```
Classic retirement advice — preserve Roth last (tax-free growth, no RMDs).
